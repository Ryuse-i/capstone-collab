Gane-Sarson notation

External Entities

NameRole
STUDENTGlobal student role; manages projects, tasks, submissions, team interactions, resources, meetings, and messages within authorized project scopes.
INSTRUCTOR / ADVISORGlobal instructor role and project-level advisor role; creates or views project work and supervises project tasks and members.
ADMINGlobal admin role; administers users, system metrics, activity logs, and repository papers.
AI PROVIDERSGemini and OpenRouter services used for task complexity analysis and paper metadata extraction.
ZOOMExternal meeting provider used through Zoom credentials to create and retrieve meeting details.
SUPABASEExternal object storage for uploaded files and PDFs in the upload bucket.

Assumptions

  • The external user roles are based on UserRole.ADMIN, UserRole.STUDENT, and UserRole.INSTRUCTOR; project-level advisor is shown with INSTRUCTOR / ADVISOR because the frontend routes also permit that project role.
  • Google Meet is not drawn as a separate external API entity because the code accepts an externally created Google Meet URL and performs no Google API call. It is included under the meeting-provider implementation.
  • Supabase object storage is shown as external storage; the exact bucket is upload, while paper metadata and file metadata are stored in PostgreSQL tables.
  • The 32 named PostgreSQL stores are represented as exact table names. No migration-only table without a corresponding model was inferred.
